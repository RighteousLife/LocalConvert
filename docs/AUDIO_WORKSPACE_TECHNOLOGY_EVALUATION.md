# Audio Workspace — Technology & Framework Evaluation

**Document ID:** LC-AW-TECH-003  
**Target Platform:** macOS 15.0+, Apple Silicon (`arm64`), Xcode `27.x` SDK, Swift 6 (`SWIFT_STRICT_CONCURRENCY: complete`)  
**Phase Status:** Phase 61.1 Corrected Technical Specification

---

## 1. Guiding Selection Principles

1. **Native Apple APIs First:** Use Apple system frameworks wherever they provide deterministic, hardware-accelerated, zero-process-overhead decoding, playback, DSP, rendering, or device routing.
2. **Bundled FFmpeg 9.0.2 (`LGPLv3+`) Selectively:** LocalConvert bundles a verified static `arm64` (`minos 15.0`) FFmpeg 9.0.2 binary built with `libmp3lame` 4.0, `libmpg123` 1.33.7, `libopus` 1.6.1, and `AudioToolbox`/`VideoToolbox` integration (`LocalConvert/Resources/ffmpeg/FFmpeg-BUILDCONF.txt`). Reserve FFmpeg for codecs/containers macOS does not encode or tag natively, rather than spawning CLI subprocesses for interactive playback, scrubbing, or natively readable waveform peaks.
3. **Zero New Third-Party Dependencies:** Rely exclusively on macOS 15 system frameworks (`AVFoundation`, `AudioToolbox`, `CoreAudio`, `Accelerate`, `SwiftUI`/`CoreGraphics`, system `libsqlite3`) so binary portability (`minos 15.0`), LGPLv3+ compliance, codesigning, and `./scripts/verify-dependencies.sh` remain intact.

## 4. Export Semantics Clarification & Critical Engineering Trade-Offs

1. **Terminology Alignment (Correction C):** Selecting FLAC, ALAC, WAV, or AIFF in `AudioExportService` guarantees a **Lossless-Format Re-Render** (zero lossy compression artifacts on output), **NOT** bit-exact equality with the original source whenever gain, fades, crossfades, EQ, dynamics, mixing, sample-rate conversion, channel mapping, or 16-bit dithering occur. Only an unedited **Bit-Exact Pass-Through** preserves original PCM/bitstream samples.
2. **Phase 68 Export Fixes Identified During Audit:**
   - Replace `AudioExportService.swift:502` `-c:a libvorbis` (mismatch against bundled FFmpeg 9.0.2 `vorbis` codec) or gate `.ogg` appropriately.
   - Include `.alac` in 16-bit TPDF dither logic when down-quantizing Float32 mixdowns to 16-bit ALAC, and update `validateExportedFile` to verify bit depth (`bits_per_raw_sample` / `sample_fmt` / native `AVAudioFile.fileFormat`) as well as codec name.
   - Support multichannel (`> 2` ch) export explicitly if multichannel editing is enabled, or clearly restrict UI/validator to Mono/Stereo (`1...2` ch) when using `AudioMixSession`'s stereo mix bus (`left/right` buffers).
3. **FFmpeg PCM Pipe vs Disk Proxy Cache for Non-Native Waveforms:** Piping `ffmpeg -f f32le -` output chunks directly through `Accelerate` (`vDSP`) avoids creating multi-gigabyte intermediate WAV/CAF files just to display waveforms for `.opus`/`.ogg`/`.wv`/`.ape` tracks in large libraries.
4. **No SQLite Wrapper Bloat:** Implement `actor SQLiteLibraryDatabase` directly over macOS system `libsqlite3` (`import SQLite3`) with WAL mode, Option A external-content `FTS5` triggers, runtime `sqlite_compileoption_used('ENABLE_FTS5')` probe, parameterized `LIKE` fallback, and explicit prepared statements (`sqlite3_bind_*`).
