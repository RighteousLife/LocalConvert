## 2. Privacy, Storage & Test Isolation Guarantees

Every unit, integration, performance, and UI test in Audio Workspace MUST preserve **Phase 58 / Phase 58.1** and **Phase 60** guarantees:

1. **Test Sandbox Only (`TestSandbox` + `AppStoragePaths`):**
   - Zero reads/writes to `~/Library/Application Support/com.localconvert.app/`, `~/Library/Caches/com.localconvert.app/`, `~/Library/Logs/LocalConvert/`, or `UserDefaults.standard` (`com.localconvert.app`).
   - All new Audio Workspace storage URLs (`audioLibraryDatabaseURL`, `audioWaveformCacheDirectory`, `audioPlayerStateURL`, `audioExportStagingDirectory`) resolve through `AppStoragePaths` and automatically redirect inside `AppStoragePaths.activeTestSandboxRoot`.
2. **Privacy-Preserving Diagnostics (`StructuredDiagnostics`):**
   - New categories (`.audioLibrary`, `.audioPlayer`, `.audioWaveform`, `.audioEditor`) sanitize all messages via `ErrorDetailsFormatter.sanitize(_:)`, never logging user paths, ID3/Vorbis tags, lyrics, or artwork metadata in plaintext `.public`.
3. **QoS-Clean Asynchronous Test Fixtures (Phase 60 Pattern):**
   - Introduce `SyntheticAudioFixtureWriter` in `LocalConvertTestSupport/` generating deterministic sine/chirp/impulse/silence WAV, AIFF, CAF, ALAC, and FLAC fixtures using `async throws`, `withTaskCancellationHandler`, and `withThrowingTaskGroup` — strictly **zero `DispatchSemaphore.wait()`** and **zero `Task.detached`** from `@MainActor` test callers.

- **Real Audio Decoding Parity:** Decode synthetic WAV, AIFF, CAF, ALAC (`.m4a`), AAC, MP3, FLAC, Ogg, Opus, WavPack fixtures via native `AVAudioFile` + FFmpeg fallback, verifying frame counts and durations within codec tolerances.

- **Genuine Format Matrix (Env-Gated Optional):** Optional `LOCALCONVERT_AUDIO_SAMPLES_DIR` matrix (paralleling Phase 56 `LOCALCONVERT_RAW_SAMPLES_DIR`), cleanly `XCTSkip`-gated when unset.
